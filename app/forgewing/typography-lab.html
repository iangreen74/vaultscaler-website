Preview renders at the active viewport. Class string at the bottom of each card always shows the full responsive output.
How to read the class strings: sizes appear as text-base sm:text-lg lg:text-xl; the sm: and lg: prefixes are added only when those size buckets differ from the previous bucket. DM Serif Display is applied via inline style on the page (Tailwind doesn't have a built-in serif token here), so serif roles show a comment in the output. Color tokens map to Tailwind arbitrary values like text-[#1E3340] or named opacity utilities like text-white/85.
